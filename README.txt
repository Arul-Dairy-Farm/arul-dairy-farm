# Arul Dairy Farm & Cow Care Trust Website

## Files
- `index.html` — main website
- `style.css` — responsive styling
- `hero-banner.png` — your uploaded hero banner

## How to open
Double-click `index.html` to open the website in Chrome/Edge.

## Important before publishing
1. Replace the phone number and email in `index.html`.
2. Replace the Razorpay placeholder link (`https://rzp.io/`) with your real payment/donation link.
3. Add more farm/cow photographs in the Gallery section.
4. If you buy a domain, upload these files to your hosting account.

The website is responsive and includes a mobile navigation menu.
